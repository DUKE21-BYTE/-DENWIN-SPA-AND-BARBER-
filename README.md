# Denwin Spa & Barbershop - Static Website

Welcome to the **Denwin Spa & Barbershop** static website project. This is a multi-page, responsive, and visually stunning web experience built with modern HTML and Tailwind CSS.

## 🌟 Project Overview

This project is a static site designed to showcase the premium services, team, and booking flow of "Denwin Spa & Barbershop" (formerly Fellas Spa).

### Key Features

- **Modern Design**: Dark mode aesthetic with gold accents (`#f9d006`) and glassmorphism effects.
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices using Tailwind CSS.
- **Interactive Components**: Hover effects, smooth transitions, and intuitive navigation.
- **Comprehensive Pages**:
  - **Home (`index.html`)**: Landing page with hero section, about, and service highlights.
  - **Services (`services-portfolio.html`)**: detailed service menu with pricing.
  - **Team (`meet-the-craftsmen.html`)**: Profiles of the expert barbers and stylists.
  - **Gallery (`gallery.html`)**: A visual showcase of the shop and work.
  - **Booking (`book-experience.html`)**: A simulated multi-step booking flow.
  - **Dashboard (`my-account.html`)**: A user account view for managing appointments.
  - **Confirmation (`booking-confirmation.html`)**: Success page after booking.
  - **404 (`404.html`)**: Custom error page.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure for better SEO and accessibility.
- **Tailwind CSS (CDN)**: Utility-first CSS framework for styling and responsiveness.
- **Google Fonts**: "Manrope" font for modern typography.
- **Material Symbols**: High-quality icons via Google Fonts.
- **Node.js (Optional)**: Included `server.js` for local development.

## 🚀 Getting Started

To run this project locally, you have two options:

### Option 1: Simple File Opening

Simply open `index.html` in your preferred web browser. Most modern browsers will render the site correctly.

### Option 2: Local Server (Recommended)

If you have Node.js installed, you can run the included simple server to mimic a production environment.

1.  Open your terminal in the project directory.
2.  Run the server:
    ```bash
    node server.js
    ```
3.  Open your browser and navigate to:
    `http://localhost:3000`

## 📦 Deployment

This site is static-ready and can be deployed instantly to platforms like **GitHub Pages**, **Netlify**, or **Vercel**.

### GitHub Pages Method

1.  Go to your repository settings on GitHub.
2.  Select "Pages" from the sidebar.
3.  Under "Source", choose `main` branch.
4.  Save. Your site will follow the URL provided by GitHub.

## 🔒 Security & Robustness

- **HTTPS**: Ensure your hosting provider (like GitHub Pages) forces HTTPS.
- **External Assets**: All external CSS/JS (Tailwind, Fonts) are loaded via HTTPS.
- **No Backend Risk**: As a static site, there is zero risk of database injection or server-side vulnerabilities.
- **SEO Friendly**: Semantic HTML tags (`<header>`, `<main>`, `<footer>`, `<section>`) are used throughout.
